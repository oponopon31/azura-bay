AZURA BAY — a sun-soaked open-world crime game: drive and steal cars across a coastal city, outrun a 5-star police dispatch with roadblocks and a helicopter, run 10 story missions, fight, upgrade your garage, and save your progress. Play it with `node serve.ts`, then open http://localhost:8080.

## Run it

```sh
node serve.ts
```
